# Dayora — Your Daily Growth Space

## Menjalankan di VS Code
1. Ekstrak ZIP.
2. Buka folder `dayora-vscode` di VS Code.
3. Pastikan Node.js versi 18+ sudah terpasang.
4. Buka Terminal > New Terminal.
5. Jalankan `npm install`.
6. Setelah selesai, jalankan `npm start`.
7. Buka http://localhost:3000 di browser.

Tidak perlu API key. Data disimpan di browser menggunakan LocalStorage.
Untuk menghentikan server tekan Ctrl+C di terminal.
